# 盈亏方向分歧增强观察 v1

规则版本：`profit-support-v1`，2026-10-29。

## 定义

分别取竞彩源站和非让球模拟的胜、平、负三项盈亏率中数值最低的方向。容差为`1e-9`，并列全部保留；两套最低方向集合没有交集时，匹配“盈亏方向分歧”标签。

最低值指该套输入假设下利润最低（最亏或盈利最少），不代表已知庄家意图。源站率和模拟ROI来自不同赔率、投注分布及计算口径，分歧不是数据采集错误的判定。

## 输入与缺失

- 仅用于有竞彩编号的比赛。
- 竞彩使用已有严格字段`frontendAnalysis.weightedFeatureInputs.officialProfitRates`，三项都必须为有限数。真实0有效；缺失为`null`，禁止从旧接口默认0的市场字段回填。
- 模拟使用唯一一份非让球`simulated`市场，排除`sportteryRqspf`和`sportteryRqspfSim`。赔率有效、三项可用、测算基数大于0时，以`bookmakerProfit * 100 / totalStake`计算各项ROI。
- 缺任一套三项输入、重复模拟来源、无效金额或赔率时显示“待判”，不归入无增强组。
- 分类不读取本场比分、完赛状态或实际赛果。

## 与入选的关系

原固定模型和`secondary-v1`的0.225门槛保持不变。新标签不增加、剔除或重新打分任何候选。

- 已二次保留且匹配：显示“二次增强”。
- 匹配但没有二次保留：显示“盈亏分歧”，并注明仅特征匹配、未二次保留。
- 两套最低方向存在共同项：显示“无此增强”。
- 新列同时显示两套最低方向与相应盈亏率，可悬停查看完整三项数据。

## 完整窗口统计

沿用所选日期、赛事范围、联赛和搜索条件的完整窗口，不受标签、平局次数过滤或分页影响。仅在已有二次候选中分组：

- 二次可比基准＝增强组＋有共同方向组。
- 全部二次候选＝可比基准＋待判组。
- 分组命中率＝该组命中平局数／该组确认常规时间完赛数。
- 平局覆盖率＝该组命中平局数／窗口全部竞彩确认完赛平局数。
- 未完赛单列待赛果，零分母显示“—”。

支持组的命中率不代表整个候选池。按当前快照展示，尚未锁定首次赛前决定；输入补齐和赔率变化会改变标签。当前回看不是独立的未来验证。

## 历史复核基准

2026-10-29 09:15:31 UTC的数据库快照：552场竞彩、135平；原模型341场中129平，二次保留305场中125平。

二次可比基准296场中124平（41.89%）；其中增强141场中66平（46.81%，覆盖全部135平的48.89%），共同方向155场中58平；待判9场中1平。

这些样本包含模型训练数据，且已反复探索，不承诺未来增益。原模型参数和二次门槛没有重新训练或调整。

## 加载与验证

行标签在前端从已有严格输入直接计算，无新增查询请求。全窗口增强统计由后端在既有Redis日结果上派生，无新增SQL和缓存数据格式迁移。旧接口缺少严格源数据时待判；缺少新统计字段时提示后端待更新。

由用户自行重启28080分析服务加载增强统计，再刷新后台；助手不启停服务。

离线验证：`node scripts/verify-draw-profit-support.cjs`；前端构建：`cd admin`后执行`npm run build`。Go单测覆盖分类、聚合及可选的全量快照复核。
