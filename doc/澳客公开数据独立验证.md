# 澳客公开数据独立验证

本阶段只做独立采样，不接管生产采集。VIPC 仍保留为原数据源；恢复后继续使用原入口。本验证不添加自动切换或自动回切。

## 隔离边界

- 独立脚本：`scripts/probe-okooo-public.py`，不被现有服务或爬虫调用。
- 只访问澳客 HTTPS 公开网页；不注册、不付费、不读取用户 Cookie，不尝试绕过登录、付费或访问挑战。
- 不访问数据库、本地业务接口、VIPC、服务配置或定时任务。
- 输出只写到 `reports/source-probes/okooo/<UTC运行时间>/`；每次新建目录，不覆盖历史报告。
- 澳客比赛 ID 单独记录，`vipc_match_id` 保持空；不按相似名称直接覆盖旧比赛。
- 澳客竞彩保存比例、保存盈亏、必发数据不得写入 VIPC 原投注比例、盈亏、冷热字段。
- 不启动、停止或重启项目程序、服务。

## 运行

需要 Python 3 和 Beautiful Soup 4（当前环境已有）。在项目根目录执行：

```powershell
python scripts/probe-okooo-public.py --date 2026-11-13 --limit 10
```

日期为源站赛程页面日期，需显式指定。最多采样 10 场，请求起始间隔默认 1.5 秒，无自动重试。列表仅选择对应日期的竞彩行，不使用搜索引擎缓存或其他日期补足样本。

采集页面：竞彩列表，以及每场历史、欧赔、亚盘、大小球、比分、总进球、交易盈亏。HTTP 拒绝、超时、缺失均保留。中途停止时，已完成请求的报告仍保留。

## 输出解释

- `raw/*.bin`：原始响应字节，包括可读取的错误响应；报告记录 SHA-256、采集时间、地址和编码。
- `report.json`：样本身份、请求状态、表格原始单元格、数据行候选、权限提示。
- `report.html`：本地简要检查表。

HTTP 200、菜单文字或数值候选不等于字段可用。脚本不会把未映射的表格冒充为已确认赔率。历史候选要求同一行存在日期和比分；数值候选仍需要核实公司、市场、初即时盘、数值单位及赛前时间。

下一阶段只有在验证数据质量后才考虑来源适配。任何接入仍须保留来源身份、原始快照与缺失原因；不得无声混入现有 VIPC 数据或将两种来源的盈亏作为同口径连续历史。
